# Warm-Up 02 – Programming 101

## What is Programming?

Programming is the process of writing instructions for a computer to perform specific tasks.

A program is a collection of instructions executed one by one.

---

## Programming Workflow

```
Problem
   ↓
Analyze
   ↓
Algorithm
   ↓
Write Code
   ↓
Compile / Interpret
   ↓
Run Program
   ↓
Output
```

---

## Basic Building Blocks of Programming

### 1. Variables

Variables are used to store data.

Example:

```javascript
let name = "Rajesh";
let age = 22;
```

---

### 2. Data Types

Common data types:

* Number
* String
* Boolean
* Undefined
* Null
* Object

---

### 3. Input

Input is the data provided to a program.

Example:

```javascript
let num = 10;
```

---

### 4. Output

Output is the result produced by the program.

Example:

```javascript
console.log(num);
```

---

## Operators

### Arithmetic Operators

* `+`
* `-`
* `*`
* `/`
* `%`

Example:

```javascript
let a = 10;
let b = 5;

console.log(a + b);
console.log(a - b);
console.log(a * b);
console.log(a / b);
console.log(a % b);
```

---

## Comments

Comments improve code readability.

Single-line comment:

```javascript
// This is a comment
```

Multi-line comment:

```javascript
/*
This is
a multi-line comment.
*/
```

---

## Best Practices

* Use meaningful variable names.
* Write clean and readable code.
* Keep programs simple.
* Add comments when necessary.
* Practice regularly.

---

## Key Takeaways

* Every program starts with a problem.
* Variables store data.
* Operators perform calculations.
* Input is processed to produce output.
* Writing clean code is an important habit from the beginning.
